## HTTP 记录边界

- 1,235 个失败任务保存了 HTTP index，共 6,058 条记录；成功任务没有 HTTP index。
- 旧记录没有 `attempts` 字段，因此 retry 次数为 `UNVERIFIED`，不能解释为零。
- 失败任务记录中可确认 25 个重复 GET，均归于 `javbus`；这是下界。
- 旧批次没有 `fd2ppv` 记录，因此 FD2PPV 同详情页重复请求为 `UNVERIFIED`，不能解释为零。
- 基于不完整 HTTP 记录计算的平均请求数不用于升级前后结论。
