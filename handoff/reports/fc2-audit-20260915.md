## 请求、认证与共享域名

- DMM 搜索固定请求 `www.dmm.co.jp`, GraphQL 固定请求三种 `api.*` host; 修改 base_url 不会替换这些 API host.
- official 无单一 base_url; 按 MANUFACTURER_DOMAINS 构造 `/works/detail/{number}`.
- Wikipedia 起点为 Wikidata, 后续固定日文/中文 Wikipedia 及移动域; gFriends 实际读取 raw.githubusercontent.com, GitHub URL 是仓库/展示入口.
- JavDB 与 ThePornDB 各有影片和演员 crawler, 共用同一 host 许可, 不按实例各建限流器. 同 host 多来源默认速率取更小值, network 显式覆盖优先.
- CrawlerFactory 向所有 crawler 注入同一 HttpClient/WebClient; worker 并发、重试与重定向都不能绕过该进程内许可. 多个独立 Amane 进程不共享内存限速.
- `SiteConfig.cookie` 继续由 Crawler 基类合并, FC2 官方现已传递 cookies/headers. 跨 host 重定向丢弃显式 Cookie/Authorization. 原生会话 Cookie 仍遵循客户端 cookie jar 的域规则.
- 现有 `use_proxy` 字段未由 CrawlerFactory 创建独立传输; crawler 仍使用统一 network.proxy. 本轮保留此既有行为, 未重构代理系统.
- 抖动围绕额外等待在 0–60% 区间变化, 相当于额外 30% ±30%; 不允许负抖动突破最短间隔. 404 负缓存 12h, 仅进程内, 不缓存 Cookie/认证失败. 403 不重试; 429/5xx 有界重试, Retry-After 超过最大等待则结束当前请求.

## 候选源与证据

- FC2 官方: 复用 `fc2`, 不重复注册 `fc2_official`; 数字商品详情 `/article/{id}/`. 原始标题位于 raw.fc2, 不新增 original_title 数据库列.
- JavArchive: 本轮 HTTP 200; 搜索表单 `/search?q=...`, 精确匹配详情链接; `.Recipepod .name`, `.news` 作品标签与图片区域经原始 HTML 检查. 不把文章发布日期填入 release. 无独立演员信息; 不伪造标签.
- FC2CMADB/FD2PPV: 从指定会话的已验证本地源码迁入, 保留 Inertia/DOM 和图片映射. FC2CMADB 登录页不作为作品标题; FD2PPV 自动化可用性仍受站点挑战限制.
- MissJAV: missjav.com 网页读取失败, 发现的 missjav.to 本机 TLS 连接失败; 未取得可靠详情结构, 不注册假 crawler.
- Thikana: 未找到可确认的 FC2 元数据入口, 等待准确网址; 7MMTV/AV01 作为第二阶段来源不注册, 尚无低维护可用性证据.
- 仅技术结构与汇总进入 Git, 原始网络 HTML 存于被忽略的 data/research, 不进入提交.
